# Where things stand

A snapshot of what exists, what is deliberately unfinished, and what has already been
tried and rejected. The rest of the documentation explains how the game *works*; this
file exists so that decisions made in conversation aren't lost when the conversation is.

Update it when something here stops being true.

## The game today

Playable end to end: welcome screen, board, game over. Deployed on Vercel from `main`.

- **Board:** two rings, 19 cells. `config.board.rings` changes it; three rings still works.
- **Words:** ENABLE, filtered (see [ADR-0007](adr/0007-banned-words.md)), packed to a DAWG.
- **Boards:** generated by refinement, aiming for long words and word families
  ([ADR-0006](adr/0006-board-generation-by-refinement.md)).
- **Bees:** two kinds, arriving in waves, at most one of each on the board.
- **Levels:** ten, in `src/config/levels.ts`.
- **Tests:** 212, covering the rules, the dictionary, the generator, and the wiring
  between layout, renderer and input.

## Numbers nobody has validated

These were derived from arithmetic, not from play. Treat any of them as a first guess:

- `harvestPercent` per level (the clock replaced the health drain — see ADR-0008)
- the ten `honeyThreshold` values
- `waveMs` / `calmMs` / `speed` per level
- `rarityHarvest` per letter

The board generator's output *has* been measured — roughly 41/28/19/8 across word
lengths, and board-to-board overlap around 0.035.

## Never measured at all

**Performance on a real device.** The game targets 60fps on mobile web and nobody has
opened it on a phone with a profiler. The pixel-ratio cap, the cached environment
backdrop and keeping React off the per-frame path are all untested assumptions.

**Cold load.** Roughly 340 KB on a first visit: ~82 KB of JavaScript, ~225 KB of packed
dictionary, and two fonts. Never measured on a slow connection.

## Approved but not built

- **The mute icon is still small.** Enlarging the glyph inside its unchanged 44px tap
  target was agreed and then lost in a revert. At its current size it reads as a smudge
  against the grass.

## Proposed, not agreed

- **The pot as a jar.** The score is a number in a corner while a quarter of the screen
  below the board is empty. At two rings the board is width-capped, so that vertical
  space is permanent — it should be used rather than reduced. A jar filling with the
  same honey the cells lose would reuse the existing liquid renderer.
- **HUD rebalance.** Resolved by the clock: the health bar it referred to no longer
  exists, and the clock that replaced it is the same weight as the pot by design.

- **Freshness tests do not cover the shipped generator.** The sharper three — no
  ubiquitous word, vocabulary breadth, most words on one board only — run against the
  alternative weighted-bag generator. The shipped family generator, whose objective
  deliberately narrows the space of boards, is guarded only by mean pairwise overlap
  and board uniqueness. It is the one that most needs them. See
  [letters.md](./design/letters.md).

## Parked ideas

- **Corner cells.** Using the four empty corners beside the hexagon for extra letters.
  Explicitly deferred, not rejected.
- **A second theme, working title "Wu-Tang Spellah Bees".** The theme system was built
  to make this possible: palette, typography, sprites, sounds, copy and environments are
  all swappable, and the generator and dictionary are independent axes so a theme can
  bring its own. Note that the name is an active trademark — a licensing conversation,
  not a technical one.
- **An options screen** for toggling variations. Dropped: config is edited directly and
  redeployed instead.

## Tried and rejected — do not re-propose without a new reason

These were built, looked at, and reverted. The reasoning matters more than the list:

- **Capping honey below a cell's rim** so a band of wax always shows. Cells filled to
  the top look cleaner and more deliberate, and that beats making the liquid visible
  when nothing is happening.
- **Shading a trail by age** (oldest dark, newest bright) with a brighter ring on the
  most recent cell, to show which way a word runs. Too subtle to read. Trail order is
  currently unsolved and that is accepted until a better idea turns up.
- **Shrinking the word preview** below the size of the board's letters. The large word
  is correct; the dark plate behind it was the part worth keeping.

The principle behind all three: this game favours a clean, deliberate, filled-in look
over material realism, and the word being read is allowed to be the loudest thing on
screen.

## Declined on purpose

- **Bundling `(x, y, size, radius)`** into a geometry type across the five drawing
  functions. It is a real data clump, but bundling costs an allocation per cell per
  frame and positional geometry arguments are the convention canvas APIs already use.

## Operational

- **`main` has diverged from `origin/main`.** A commit was reset away locally that still
  exists on the remote. Needs a force-push before anything else lands, or the next
  deploy builds the wrong tree.
- **Deploys** run from `main` via Vercel, configured in `vercel.json`.
- **Rebuilding the dictionary** needs `tools/fetch-wordlists.sh` first — the raw inputs
  are ~6 MB and deliberately not committed.
